# Лабораторная работа №2 — Многопоточное умножение матриц

## Описание проекта

Программа реализует умножение матриц с использованием многопоточности на языке C#.

Цель работы — исследовать влияние количества потоков на производительность вычислений, сравнить время выполнения для матриц разных размеров и определить оптимальное количество потоков.

## Технологии

- C#
- .NET 10
- System.Threading
- Stopwatch
- Visual Studio Code

## Реализация

В проекте используются следующие компоненты:

- **Program.cs** — точка входа в программу, создание матриц и запуск вычислений.
- **Matrix.cs** — создание, вывод и сравнение матриц, однопоточное умножение.
- **MatrixMultiplier.cs** — многопоточное умножение матриц с распределением строк между потоками.
- **Benchmark.cs** — проведение измерений производительности и сохранение результатов в CSV.

Для синхронизации потоков используются `Interlocked`, `Volatile` и `Thread.Join()`.

## Проведение экспериментов

Для исследования производительности используются матрицы следующих размеров:

- 500 × 500
- 1000 × 1000
- 2000 × 2000

Проводится сравнение работы программы при разном количестве потоков: от 1 до 16, а также при 32 и 64 потоках.

Для каждой конфигурации выполняется 5 измерений. Минимальное и максимальное значения исключаются, после чего рассчитывается среднее арифметическое оставшихся трёх результатов.

Результаты измерений сохраняются в файле `Report/benchmark.csv`.

## Требования

- Установленный .NET SDK 10.0 или совместимая версия.
- Операционная система с поддержкой .NET.

## Сборка проекта

Клонируйте репозиторий:

```bash
git clone https://github.com/IvanKazanthev/LAB2_OS.git
```

Перейдите в каталог проекта:

```bash
cd LAB2_OS
```

Выполните сборку:

```bash
dotnet build -c Release
```

## Запуск программы

Для запуска умножения матриц с заданными параметрами используйте:

```bash
dotnet run -c Release -- 3 3 3 2
```

Параметры команды:

1. Количество строк первой матрицы.
2. Количество столбцов первой матрицы.
3. Количество столбцов второй матрицы.
4. Количество потоков.

## Запуск измерений производительности

Для проведения серии экспериментов выполните:

```bash
dotnet run -c Release -- benchmark
```

Результаты будут сохранены в `Report/benchmark.csv`.

## Проверка корректности

После многопоточного умножения программа выполняет однопоточное умножение тех же матриц и сравнивает результаты с допустимой погрешностью `0.000001`.
